## What is included

The release includes:

    CLI command surface
    product schemas
    message prepare/send/receive flow
    receipt production
    receipt-chain verification
    VTP verification surface
    signed test vectors
    demo policy
    public allowed signers
    clean-bundle demo registry bootstrap

## What is not included

This release is not yet:

    a polished desktop app
    a background service
    a hosted platform
    a production identity system
    a production key-management system
    a final user experience
